## 🌟 プロジェクトの概要

HomeruAIは、iPadなどのタブレット端末で利用できるWebノートアプリケーションです。
単に問題の正解・不正解を判定するだけでなく、**「解答に至るまでのプロセス」をAIが深く分析して評価（ほめる）** ことを最大の特徴としています。

学習者がアプリ上で問題を解くと、AIが以下のデータを多角的に分析します：

- **筆跡**（どのように書き進めたか）
- **消しゴムでの消去履歴**（試行錯誤の跡や、正しかったのに消してしまった思考）
- **回答に迷った時間や場所**（ペンが止まっていた時間）
- **筆圧**（Apple Pencil等のデータ）

これらのデータを元に、「どこで迷ったのか」「問題に取り組む姿勢」「消してしまった思考の跡」までをAIが汲み取ります。学習者の弱点を発見して改善の道筋を示すだけでなく、プロセスそのものを「ほめる」ことで、モチベーションの向上と自発的な学習につなげます。

ノートは教材画像を含めてブラウザ内へ自動保存されます。GeminiのAPIキーが未設定、またはAIサービスが一時的に利用できない場合も、筆跡・書き直し・停止後の再開を根拠にしたローカル称賛カードを返すため、プロトタイプの基本体験を試せます。

PDF教材は「挿入」から読み込むとページごとのノートになり、その上へ直接書き込めます。写真、入力した問題文、白紙への手書き問題にも対応しています。複数の設問が写っている場合は「問題範囲」で対象だけを囲めます。

画面上部の「成長を見る」では、習得度、自分で進める力、粘り強さ、見守り度の現在地と推移、学習回数、書き直し・再開の積み上げを確認できます。難しい問題で推定値が上下しても、取り組みを表すXPは減りません。「Debug」では研究用のX1〜X4、分析特徴、AI障害分類、Apple Pencilの筆圧・傾き・パームリジェクション動作を確認できます。

## 🚀 起動方法

```powershell
# ターミナル1（リポジトリルート）
python -m venv backend\venv
backend\venv\Scripts\pip.exe install -r backend\requirements.txt
backend\venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --port 8000 --reload

# ターミナル2
cd frontend
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。実AI分析を使う場合は `backend/.env.example` を `backend/.env` にコピーし、APIキーを設定してください。

### 研究データの出力と再学習

研究ログは `backend/data/homeruai.db` に保存されます。学習者IDはハッシュ化され、生画像・Base64・ストローク点列は保存されません。

```powershell
# 派生特徴量だけをCSVへ出力
backend\venv\Scripts\python.exe backend\scripts\export_training_data.py

# 任意のML依存を導入して、十分なデータがある場合だけ支援境界を再学習
backend\venv\Scripts\pip.exe install -r backend\requirements-ml.txt
backend\venv\Scripts\python.exe backend\scripts\train_support_model.py
```

再学習モデルは30件以上かつ結果が2クラス以上ある場合にのみ作成されます。学習者単位で交差検証し、モデルファイルと評価値を版管理します。

## ✨ 普通のAIノートとの違い

ただ答え合わせをするAIツールとは異なり、**「プロセスを評価し、学習者のレベルに合わせた褒め方をする」** のが HomeruAI の大きな強みです。

- **消えた思考も評価**: 最終的な答えだけでなく、一度書いて消してしまった「途中式」や「迷い」のデータから、思考プロセスそのものを評価します。
- **パーソナライズされた声かけ**: 学習者のレベルや勉強への取り組み方をデータとして蓄積し、フィードバック（褒め方）を柔軟に変化させます。
  - **勉強があまり得意ではない人**: 些細なプロセスや努力をたくさんほめて、自信とやる気を引き出します。
  - **勉強が少し得意になってきた人**: ほめつつも、「ここに注目して考えてみよう」と自発的な気づきを促すアドバイスを増やします。
- **停止を断定しない**: ペンが止まっただけで「迷い」と決めず、再開・消去反復・ページ表示状態まで見て支援の必要性を判断します。
- **説明可能な4状態**: 習熟度、自主的学習行動、支援必要度、粘り強さを観測事実から推定し、人格評価には使いません。
- **成長を見える化**: 正解数だけではなく、筆記、書き直し、停止後の再開も減らないXPとして積み上げ、本人が努力の成長を確認できます。

「ほめられる喜び」から始まり、徐々に「自分で気づいて解ける経験」を増やすことで、**自発的な勉強の習慣化** をサポートします。

## 🎯 今後の展望（ロードマップ）

現在、HomeruAIはプロトタイプとして鋭意開発中（未完成）です。今後は以下の機能拡張や、実際の教育現場への導入を目指しています。

- **教育現場・先生向けのダッシュボード機能**:
  先生が一目で「どの生徒が、どの問題のどの部分で詰まっているか」を把握できるダッシュボードを開発予定です。これにより、大人数の授業において個別のサポートが難しいという教育現場の課題解決を目指します。
- **UI/UXの改善**: 学習者がより直感的に楽しく学べるインターフェースの継続的なアップデート。
- **分析AIの精度向上**: Geminiの認識結果と人手評価を比較する匿名評価セットを増やし、教材・教科ごとの認識精度を改善します。
